# PCB Format Document

This chapter details the format specification of the EasyEDA PCB file. PCB files mainly consist of the following parts:

- [Common Format](common.md): document header, canvas, layers, physical layers, preferences, etc.
- [Partition Format](partition.md): partition definitions.
- [Basic Primitives](primitive.md): nets, primitive configurations, groups, silkscreen configurations, associations, attributes, etc.
- [Pads and Vias](pad_via.md): pads and vias.
- [Shape Primitives](shape.md): lines, arcs, polygon systems, polylines, fills, regions, copper pours, images, teardrops, etc.
- [Binary Objects](obj.md): embedded objects.
- [3D Shell](3d.md): shells, creases, entities, bosses.
- [Text System](text.md): text.
- [Attributes](attr.md): attributes.
- [Dimension Tools](dimension.md): dimension annotations.
- [Footprint System](component.md): component instances.
- [Design Rules](rule.md): rule templates, rule definitions, rule selectors.
- [Panelization](panel.md): panelization parameters.
