# SCH Schematic Type Document

This chapter details the format specification of the EasyEDA schematic file. Schematic files mainly consist of the following parts:

- [Common Format](common.md): document header and canvas configuration.
- [Structural Elements](structure.md): PART sub-library and GROUP combination.
- [Attributes](attr.md): primitive attribute definitions.
- [Wires](wire.md): wires, buses, and bus entries.
- [Text](text.md): text elements.
- [Shapes](shape.md): rectangles, polygons, circles, arcs, Bezier curves, ellipses.
- [Pins](pin.md): pin definitions.
- [Components](component.md): schematic component instances.
- [Objects](obj.md): binary objects (images, etc.).
- [Tables](table.md): tables and cells.
