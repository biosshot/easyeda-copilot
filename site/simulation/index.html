Simulation and PCB analysis

Start with circuit behavior in ngspice. PCB parameter extraction targets a separate engineering question: how copper geometry and stackup affect the real board.

Available · standalone skill

From component model to waveform

  1. Search the curated library by manufacturer part number.
  2. Copy the selected model by ID. Verify subcircuit ports before including it in a netlist.
  3. Run the netlist with ngspice and inspect numerical results, logs and plots.
SPICE skill and commands ↗
Run from the SPICE skill directory
node scripts/search.mjs "LM358" --limit 3
node scripts/copy-model.mjs "<modelId>" --out ./models
node scripts/simulate.mjs circuit.cir --out results/run-01

The result directory captures the rewritten netlist and included model files for review.

Try an RC low-pass filter

The included fixture uses a 1 kΩ resistor and a 100 nF capacitor. The expected −3 dB cutoff is about 1.59 kHz from 1 / (2πRC). Use the generated AC plot or CSV to check that result.

Runnable example
node scripts/simulate.mjs examples/rc-filter.cir --out results/rc-low-pass
Download the RC netlist

Roadmap · under development

Extract PCB parameters up to 1 GHz

The roadmap targets frequency-dependent extraction from layout geometry and stackup for signal and power integrity analysis. The backend documents implemented solvers and limited acceptance cases. Physical reference acceptance and full case coverage remain open.

Thermal analysis is another area of backend research.
